# Screenshot / Preview Guidance

For investor decks, lawyer demos, or partner walkthroughs, capture these screens in order (they
map directly to the demo journey in `/demo` and the README):

1. **Landing page** (`/`) — hero + JusticeIQ ecosystem badge + "Rate My Claim" preview card
2. **Login** (`/login`) — highlight the one-click "Continue with demo account" button
3. **Dashboard** (`/dashboard`) — after loading demo data, showing both seeded claims and progress
   cards
4. **Report an Incident — category picker** (`/report-incident`)
5. **Guided intake step** (`/report-incident/personal-injury`) — mid-flow, showing progress bar,
   step counter, and the AI Assistant box
6. **Documents** (`/documents`) — uploaded evidence list with categories and "important" tags
7. **Timeline** (`/timeline`) — chronological event list for a demo claim
8. **Rate My Claim** (`/rate-my-claim`) — the score gauge, breakdown meters, and factor explanation
9. **Lawyer Matches** (`/lawyer-matches`) — matched lawyer cards with the consent flow open
10. **Claim detail / summary** (`/claims/[claimId]`) — full structured claim summary

Recommended capture size: 1440×900 for desktop screens, 390×844 for mobile screens (both layouts
are fully responsive). Use the demo account so all data is populated and no screen shows an empty
state, unless intentionally demonstrating empty/error/loading states.
